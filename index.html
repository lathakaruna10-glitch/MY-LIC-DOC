How to use

1. Customer Add

Customers → + Add → details → Save.

2. Policy Add

Policies → + Add → customer + plan + renewal date → Save.

3. Renewal

Renewal Reminder menu-ல் upcoming renewals பார்க்கலாம்.

4. PDF

Documents → Policy select → Print / Save PDF.

5. WhatsApp

Customer select செய்து Open WhatsApp அழுத்தவும்.

6. Backup

Backup & Restore → Backup Data. புதிய phone/browser-ல் Restore செய்யலாம்.
